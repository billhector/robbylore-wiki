# Episodes

Specific episodes that warrant standalone treatment — breakout interviews, signature bits, recurring references. Routine appearances live in sources, not here.

*No entries.* Unpublished as of 2026-09-24 and dropped from the homepage nav — see the note below.

## Why this folder is empty

Across 52 raw sources and five compile passes, **no episode has cleared the bar** this vault sets for a standalone page. That isn't an oversight; it's the schema working. `CLAUDE.md` says to use this folder *sparingly*, and the standing scope filter is to skip episodes by default because **episodes are sources, not pages**.

In practice everything routes elsewhere:

- Each show gets a `projects/` page, and Robby appeared exactly once on 47 of the 49 shows in the sources — so an episode page would duplicate its project page.
- Episode-specific material (a bit, a career beat, a family story) belongs on the `bits/`, `career/`, `themes/` or `people/` page for the thing itself, where it accumulates across appearances instead of being stranded in one episode.
- The two multi-appearance shows are handled at the show level: [[projects/anniewood|Anniewood]] (three Robby appearances, broken out per-episode *within* the project page) and [[projects/long-winded|Long Winded]] (two).

**The folder stays** so the capability survives without being advertised. If an episode ever genuinely earns a page — substantive material that fits nowhere else — add it here, flip this file back to `publish: true`, and restore the Episodes line to the homepage Browse list.
